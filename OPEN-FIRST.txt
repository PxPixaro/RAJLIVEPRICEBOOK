1. ZIP ko poori tarah download karke Extract All karein.
2. Extracted folder ke andar index.html Chrome/Edge me kholen.
3. VIEW BY me comma-separated Excel headings kisi bhi count me likh sakte hain.
   Example: CATAGORIES, SEGMENT, VEHICLE
4. Sync Excel ek baar chalane ke baad data browser me save rahega aur next start par automatic restore hoga.
5. Grid aur Download Pricelist PDF dono me same nested headings aur Part Number order aayega.
6. Browser status “Synced & saved” confirm karega ki next start ke liye data store ho gaya hai.
