RAJ LIVE PRICEBOOK - OFFER / SCHEME POSTERS
===========================================
1. Put JPG / PNG / WEBP / PDF poster files in this folder.
2. Open js/offers.js and add one object per poster.
3. Example:
   { brand:'BRAVO', title:'Gift Offer', file:'assets/offers/bravo-gift-offer.jpg', validTill:'2026-08-31' }
4. Re-upload the project to GitHub/Hostinger. The Offer Scheme screen will show the poster automatically.
