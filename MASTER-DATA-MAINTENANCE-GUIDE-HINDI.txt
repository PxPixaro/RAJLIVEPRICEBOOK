RAJ LIVE PRICE BOOK V58 - MASTER DATA MAINTENANCE GUIDE
========================================================

A. MAIN PRICE EXCEL - PRODUCT DATA KAHAN MAINTAIN KARNA HAI
-----------------------------------------------------------
Aap jo main Price Excel Sync karte hain, usi workbook ki product-data sheet me apne existing columns ke saath ye columns maintain karein. Columns first/header row me kahin bhi ho sakte hain; heading spelling recommended format me rakhein:

1. COMPANY PART NUMBER
   - Aapka/company ka alternate code.
   - Example: CODE = AA1002, COMPANY PART NUMBER = AF1002.

2. COMPETITOR PART NUMBER
   - Matching competitor/cross-reference codes.
   - Multiple codes ek cell me comma / slash / semicolon / space se likh sakte hain.
   - Best result ke liye reciprocal mapping rakhein: Brand-A row me Brand-B code, aur Brand-B row me Brand-A code.

3. ALTERNATE PART NUMBER
   - Same/matching alternate part codes.
   - Search is full cell text par hota hai.

4. NEW PRODUCT LAUNCH
   - New item ke row me NEW likhein.
   - Blank row normal product maana jayega.
   - New Product Launch filter isi column ko read karta hai.

5. DEAD STOCK
   - Dead-stock item ke row me DEAD likhein.
   - Dead Stock filter isi column ko read karta hai.

6. FSN CLASS
   - F / S / N / P ya future me koi bhi naya class text.
   - Filter dynamic hai; Excel me jo distinct class milega, option me aa sakta hai.

IMPORTANT:
- Existing CODE / PRODUCT NAME / UNIT / GST / RATE / MRP / SEGMENT / VEHICLE / MODEL / CATEGORY etc. headings ko delete/rename na karein jab tak mapping update na ho.
- Product CODE ko stable unique key rakhein. ERP/API integration ke time isi code se Rate/MRP/GST/Product Name sync karna best rahega.


B. CUSTOMER LOGIN MASTER - ALAG SHEET
-------------------------------------
Main Price Excel workbook ke andar ek separate worksheet banayein jiska naam EXACTLY ho:

CUSTOMER MASTER

Recommended headings:
CUSTOMER NAME | MOBILE NUMBER | PASSWORD | CUSTOMER ID | CITY | ACCESS GROUP | ROLE

Example:
ABC AUTO | 9876543210 | raj123 | C001 | SURAT | customer | customer
XYZ SALES | 9876500000 | raj123 | S001 | AHMEDABAD | salesman | customer
TRUST AUTO | 9876511111 | raj123 | T001 | RAJKOT | trusted_customer | customer

Meaning:
- CUSTOMER NAME: login ke baad Welcome/Profile me naam.
- MOBILE NUMBER: customer ka login username. Matching last 10 digits se hoti hai.
- PASSWORD: static GitHub prototype me login password.
- CUSTOMER ID: future ERP/customer-code mapping ke liye useful.
- CITY: Profile/order Excel me use ho sakta hai.
- ACCESS GROUP: salesman / customer / trusted_customer.
- ROLE: normal users ke liye customer rakhein. Pixaro built-in admin alag hai.
